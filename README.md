# PortFolioLucSarrazin

## Description

Ce dépôt contient le code source de mon portfolio (**Luc Sarrazin**), présentant mes compétences, projets, stages, certifications et expériences professionnelles. Le portfolio est conçu pour offrir une navigation fluide et un aperçu complet sur mon parcours.

## Fonctionnalités

- **Page d'accueil** : Introduction et présentation.
- **Projets** : Détails des réalisations et contributions.
- **Stages** : Informations sur les expériences professionnelles.
- **Certifications** : Liste des diplômes et certifications obtenus.
- **Contact** : Formulaire de contact intégré.

## Technologies utilisées

- **HTML / CSS** : Structure et design.
- **PHP** : Traitement des formulaires.
- **SVG** : Visuels dynamiques.

## Installation locale

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/LucSarrazin/PortFolioLucSarrazin.git
   ```
2. Déplacez-vous dans le répertoire :
   ```bash
   cd PortFolioLucSarrazin
   ```
3. Ouvrez le fichier `index.html` dans un navigateur.

## Aperçu

Le portfolio présente un design moderne et responsive, avec une navigation intuitive. Vous pouvez y découvrir mes compétences, projets, et moyens de contact. [Cliquez ici pour voir la démo en ligne](https://lucsarrazin.github.io/PortFolioLucSarrazin/).
